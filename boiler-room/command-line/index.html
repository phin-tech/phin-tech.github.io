The command line and agents

Everything the window does, boiler-room does in a terminal, and agents use it too. Help › Install Command Line Tool (or Welcome) puts it in ~/.local/bin: a link to the app's own binary, which answers a command line before opening anything. By hand, that's:

ln -s "/Applications/Boiler Room.app/Contents/MacOS/Boiler Room" \
    ~/.local/bin/boiler-room

Looking #

boiler-room status               # the service, and what to install
boiler-room service status       # running, which version, and whether it starts at login
boiler-room service restart      # restart it; start, stop and login-items too
boiler-room service settings     # daemon.toml's path, made if missing; --edit opens it
boiler-room jobs                 # every Job and Errand, and how it went
boiler-room runs aws-case-1234   # its newest Runs
boiler-room show 42              # one Run: output, errors, values, report
boiler-room templates            # Templates and their Params
boiler-room questions            # what's waiting for you

--json on most of them gives something to parse.

Doing #

boiler-room run aws-case-1234 --wait    # now, and exit as it did
boiler-room new aws-case case=1234      # a Job from a Template
boiler-room schedule aws-case-1234 3h   # or a cron line in quotes
boiler-room pause aws-case-1234         # and resume; stop <run>
boiler-room answer 3 yes                # a question
boiler-room submit --every 30s -- gh pr checks 123

From a Script #

Inside a Run, a Script reports with notify, changed, unchanged, value, report and progress, and asks with ask, confirm and wait (Being told). Outside a Run they refuse, unless given --job to try a Script by hand.

Agents #

boiler-room mcp is an MCP server, for Claude Code or any agent: it lists and reads Jobs, Runs and Templates, makes Jobs, runs them, changes schedules, hands over Errands and waits for them, and answers questions (never a hidden one). Tools that change something say so. To add it to Claude Code:

claude mcp add boiler-room -- boiler-room mcp

boiler-room skill prints a Skill that teaches an agent how to use all of this; save it as ~/.claude/skills/boiler-room/SKILL.md.

The daemon's settings #

~/.config/boiler-room/daemon.toml, read as it changes. boiler-room status says if it can't be read, and the defaults are used meanwhile.

# What reads a Job's `run` line: your login shell, or a program, as "/bin/sh"
shell = "login"

[hosts.tmux]
session = "boiler-room"    # the session tmux Runs open windows in

[hosts.zellij]
session = "boiler-room"

[hosts.hc]
machine = "vps"            # hc Runs start there, as `hc run --on vps`
