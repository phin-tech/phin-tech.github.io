Examples

Boiler Room comes with Templates for things worth checking on, and a new install puts them in your templates folder (~/.config/boiler-room/templates/) the first time it starts, with some example Jobs, paused, to switch on. List the Templates, or put them back if you've removed some:

boiler-room examples              # what there is
boiler-room examples install      # all of them; or name the ones you want

Installing never replaces a Template of the same name you already have. They're plain files in ~/.config/boiler-room/templates/ afterwards: read them, change them, copy them to make your own.

Waiting for something to finish #

These are made to be Errands: each runs until there's an answer, then tells you how it went and stops.

Template Waits for
github-pr-checks A pull request's checks: "All 16 checks passed", or which failed
github-run One GitHub Actions run, by its ID
github-branch-ci Every Actions run on a branch's newest commit: after a push, "tell me when CI on main is done"
github-pr-merged A pull request to be merged or closed
forgejo-ci A Forgejo commit's CI status (needs boiler-room secret set forgejo-token) 
boiler-room submit --template github-pr-checks repo=cli/cli pr=15041 --loud
boiler-room submit --template github-branch-ci repo=owner/name --wait

They use gh, signed in (gh auth login), and jq.

Keeping an eye on something #

These are made to be Jobs, which run on their schedule and tell you when something changes:

Template Every Tells you
aws-support-case 3h Someone replied to the case, or its status changed
agent-skills-outdated 1d Which skills installed with npx skills have updates 
boiler-room new aws-support-case case=case-123456789012-abc profile=work
boiler-room new agent-skills-outdated

The example Jobs #

A new install's Jobs folder starts with these, paused. Switch one on in the list to try it:

Job Every Tells you
Example: GitHub's status 30m GitHub's status changes
Example: Is the internet up? 5m Your connection drops, and when it's back
Example: Disk space 6h Your startup disk is over 90% full
Example: macOS updates 1d Software Update has something new
Example: Homebrew updates 1d brew outdated has something new

They're files in ~/.config/boiler-room/jobs/, worth reading for how a Job reports: each prints what it found, a line of JSON to tell you something, and keeps what it saw last in its own folder, $BOILER_ROOM_STATE.

Writing your own #

Each is a few lines of /bin/sh that checks once and prints what it found as a line of JSON: {"values": {"status": "…"}} for something to compare with the last Run, {"notify": "…", "link": "…"} for something to tell you. An Errand's Template exits 0 once it's done and 1 while it isn't, with until = "exit 0". See Jobs for everything a Template can say.
