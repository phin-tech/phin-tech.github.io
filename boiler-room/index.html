Boiler Room

Runs your scripts on a schedule and tells you when something changes.

You have a script that checks on something: an AWS support case, a pull request's CI, a page that might change. Boiler Room runs it every few hours (or every few minutes, or at nine on weekdays), keeps what it printed each time, and tells you when the answer is different from last time. The script does the checking; Boiler Room does the remembering, the scheduling and the telling.

  • Jobs are files. One small TOML file each in ~/.config/boiler-room/jobs/, so you, git or an agent can write them. A Template turns one into many: an AWS case Job for each case number.
  • It runs as your terminal would. Your login shell's PATH, Homebrew and credentials, so a script that works when you type it works when Boiler Room runs it. Secrets come from the Keychain or 1Password.
  • It notices what changed. A script can say so itself (boiler-room changed), give values to compare, or just print; Boiler Room compares with the last Run either way.
  • It tells you, once. A notification when something changes or starts failing, not every time it runs. A Loud Job also puts an alert in front of you with Slaps.
  • A script can ask you. boiler-room confirm "Rotate the key?" waits for your Yes, from the notification, the window or the alert.
  • Errands. "Run gh pr checks 123 every 30 seconds until it passes, then tell me", and it clears itself away.
  • Terminals, when a script needs one. Programs that prompt (sudo, ssh) run in a terminal you can attach to, or in a tmux, zellij or hc pane.
  • Agents can use it. A command line, an MCP server and a Skill, so Claude or another agent can set up a check and hear back.

It runs whether or not its window is open: a small background service, started at login, does the work.

Install #

Boiler Room needs macOS 14 or later. Download it from apps.phin.tech, unzip it, and move it to Applications. Open it once: it starts its background service and asks to send notifications. It updates itself.

A first Job #

A new install comes with a few, paused: GitHub's status, whether the internet's up, disk space, and macOS and Homebrew updates. Turn one on with its switch in the list, and it runs at once. ⌘N makes a Job from one of the example Templates beside them.

Or write your own. Make ~/.config/boiler-room/jobs/aws-case-1234.toml:

name = "AWS case 1234"
run = "~/bin/check-support-case 1234"
every = "3h"

It runs at once, and every three hours after. Open Boiler Room to see each Run's output, or run boiler-room jobs in a terminal.
