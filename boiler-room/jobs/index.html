Jobs

A Job is a script and when to run it: one TOML file in ~/.config/boiler-room/jobs/, named for the Job (aws-case-1234.toml is the Job aws-case-1234). Boiler Room reads the folder as it changes, so a file you save, pull with git or have an agent write is picked up at once. A file it can't read shows in the window with the reason.

A Job file #

name = "AWS case 1234"          # shown in the window; the file's name if not
run = "~/bin/check-case 1234"   # a line for your login shell, or a list
every = "3h"                    # or cron = "0 9 * * mon-fri"
jitter = "5m"                   # spread it out by up to this
timeout = "2m"                  # 10 minutes if not given
notify = "on-change"            # never, on-failure, on-change or always
loud = true                     # also an alert in Slaps
env.AWS_PROFILE = "work"
env.GITHUB_TOKEN = "op://Work/GitHub/token"   # from 1Password
op_environment = "blgexucrwfr2dtsxe2q4uu7dp4" # a 1Password Environment
secrets = ["aws-support-token"] # from the Keychain
cwd = "~/src/project"           # the home folder if not given
shell = "/bin/sh"               # what reads `run`
host = "pty"                    # where it runs: see Terminals

A new Job runs at once, then on its schedule. A Mac asleep runs nothing; at wake, a Job that missed its time runs once, not once for each time it missed.

Pause a Job, or start it again, with its switch in the window's list (or ⌘P). Change its schedule from the window (⇧⌘S, or click the schedule under its name), with boiler-room schedule aws-case-1234 "0 9 * * mon-fri", or in its file. The window and the command line change only that line and keep your comments.

What it runs in #

A Script runs as it would in your terminal: your login shell's environment, so PATH, Homebrew and your credentials are there. A run line goes to your login shell (fish, if that's yours) unless the Job or the daemon's settings name another shell. A run list (["/usr/bin/python3", "check.py"]) runs the program as it is.

Each Job has a folder of its own that's kept between Runs, as $BOILER_ROOM_STATE, for anything it wants to remember.

Secrets: boiler-room secret set aws-support-token keeps one in the Keychain (typed unseen, or piped in), and secrets = ["aws-support-token"] gives it to the Script as $AWS_SUPPORT_TOKEN. An op:// value in env, or an op_environment, runs the Script through 1Password's op run.

What changed #

After each Run, Boiler Room decides whether it's a Change, in this order:

  1. What the Script said: boiler-room changed or boiler-room unchanged, or a Notice (boiler-room notify "AWS replied").
  2. A value that's different from the last Run's: boiler-room value status "Pending customer action".
  3. Output that's different from the last Run's.

So the simplest script just prints what it found, and Boiler Room compares. A Script can also give the Run a report in Markdown, shown in the window (boiler-room report summary.md, or - to read it from stdin), and say what it's doing (boiler-room progress "3 of 5").

A Script can say when it wants to run next: boiler-room again 3m, or the line {"again": "3m"}. It's for the next Run only, so a Run that says nothing puts the Job back on its schedule: check every three minutes while something's wrong, and every half hour once it's fine, as the example Job for GitHub's status does.

notify says when you're told: on a Change and when it starts failing or works again (on-change), only about failures, every Run, or never.

Templates #

A Template is a Job with blanks, in ~/.config/boiler-room/templates/:

# templates/aws-case.toml
name = "AWS case {{case}}"
run = "~/bin/check-support-case {{case}} --profile {{profile}}"
every = "3h"

[params]
case = { about = "The support case's ID" }
profile = { about = "The AWS profile", default = "work" }

Make a Job from it in the window (⌘N), with boiler-room new aws-case case=1234, or run it once without a Job: boiler-room run aws-case case=9999 --wait. A value filled into run is always quoted for the shell, so whatever's typed stays one word. Changing a Template changes every Job made from it.
