Getting started

Rabbit Ears is a make-believe cable station on your Apple TV. You flip through channels with the Siri Remote: weather, headlines, trivia, transit, a world map, radio, screensavers, and live channels you add yourself.

Do I need the Manager? #

No. The Apple TV app works on its own.

Apple TV app only With Rabbit Ears Manager (a Mac app)
Weather, Headlines, Did You Know?, World, MBTA, Radio, Screensavers yes yes
Add channels: press Select to search (Pluto TV, Tubi, Xumo, Plex Live TV) yes yes
Move, rename, hide or remove channels yes yes, with a bigger screen and keyboard
Your own Plex server and its libraries no yes, set up in the Manager
Your own IPTV provider, its channels, sports and On Demand no yes, set up in the Manager
Live feeds shared by every screen in the house (planes and so on) each TV fetches its own fetched once, shared

The Manager is for setting things up, pairing with Antenna Tower (tower/) over your home network (no iCloud involved). It isn't on TestFlight or any store: you build it from this repo (see below).

Install on your Apple TV (TestFlight) #

  1. Install TestFlight from the App Store on your Apple TV (or on an iPhone signed in to the same Apple ID).
  2. Accept the invite email, then open the TestFlight link and install Rabbit Ears.
  3. Open it. It starts on channel 1 (Weather).

Using it #

  • Swipe left / right: change channel. Swipe up / down: change page on channels that have pages (weather, MBTA, World).
  • Click (Select): open the menu or search. Hold Select on a result for its options.
  • Play / Pause: mute and unmute.
  • Menu: go back or close.

The dial starts with no preset channels. Add what you like from search: type a name, pick it, press Add. Each channel keeps its number; type a number to move it. Gaps in the dial are normal, like real TV.

Set up with the Manager (optional) #

You need a Mac with Xcode 26 and XcodeGen and just (brew install xcodegen just).

git clone https://github.com/phin-tech/retrotv
cd retrotv
just manager-install     # builds Rabbit Ears Manager into /Applications and opens it

Then, in the Manager: put in your Plex server or your IPTV provider's login, add channels, and set numbers and names.

Building under your own Apple developer account. The project is signed with Sam's team by default. Pass your own (your 10-character Team ID, and a bundle prefix you own) and nothing in the project needs editing:

just --set team ABCDE12345 --set prefix com.example manager-install
just --set team ABCDE12345 --set prefix com.example tv-install      # your Apple TV

Or set RETRO_TEAM and RETRO_PREFIX once in your shell and use the plain recipes. Every recipe takes them, and tv-install also takes your TV's name (just tv-install "Bedroom").

Pairing with Antenna Tower. The Manager and every screen talk to Antenna Tower (tower/) using a pairing code or invite link (and R2 when away), not iCloud, so a Manager you build under your own team can manage a TestFlight TV app too.

Adding IPTV (a provider's live channels, movies and series) #

Rabbit Ears doesn't include or recommend any IPTV provider. You bring your own subscription, from whoever you buy it from (a provider's own site, or a reseller listing on a marketplace such as g2g.com), and the app plays what that subscription allows. Because this is set up in the Manager, pair the Manager and your TV app with your Antenna Tower (see above).

What you get from the seller, after you pay, is one of these:

  • An M3U link, which looks like http://server.example:8080/get.php?username=...&password=...&type=m3u_plus. This is the easiest.
  • A server address, a username and a password. The server is sometimes called the host, portal or DNS, and may end in a port such as :8080.

Then, in the Manager:

  1. Open the IPTV pane and choose Add Provider….
  2. Give it a name if you like ("Strong"). Paste the M3U link into Playlist links and press Connect. If the seller gave several links for the same login, paste them all, one per line: the extras become backups for when one stops answering. No link? Fill in Server, Username and Password under "Or sign in with your login" and press Connect.
  3. When it connects, you'll see the provider's categories and channels. Check the ones you want and add them: each becomes a channel on your dial with a number. The same channel from a second provider can be added as a backup feed to a channel you already have, not as a second channel.
  4. Your login is kept in Antenna Tower so the Apple TV can play the channels. Movies and series show up on the On Demand channel; the Manager's On Demand pane picks which categories it lists.

If a channel won't play, the Audit pane checks them. The channels' TV guides come from the provider, and Find Guides… in the Live TV pane fills in the ones it lacks.
