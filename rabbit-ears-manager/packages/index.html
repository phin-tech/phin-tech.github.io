The station's packages

Sources/Shared originally held everything the apps shared: models, providers' clients, settings, views, and players. It was first split into separate SwiftPM packages by layer (so a Swift server could build on Linux without views: history/linux-server.md), and later consolidated into a single multi-target manifest at Packages/Package.swift (Swift 6.0, .macOS(.v14), .tvOS(.v17), .iOS(.v17)) once Antenna Tower moved to Go (tower/).

The app folders under Sources/ hold only thin @main entry points, plists, and assets:

  • Sources/TVApp/ (RetroTVApp.swift) — shared by RetroTV-macOS and RetroTV-tvOS
  • Sources/Manager/ (ManagerMain.swift) — RetroTV-Manager
  • Sources/iOS/ (PhoneApp.swift) — RetroTV-iOS, delegating UI to PhoneUI

Rules #

  • Nothing in StationCore draws. No SwiftUI, AVKit, VLCKit, MapKit or SceneKit. AppKit and UIKit appear only behind #if os(…), for lifecycle notifications.
  • A model doesn't live in its view's file. When a type is both what a thing is and how it looks, split it. A channel module is a ModuleDefinition (in StationCore's Station/ModuleDefinitions.swift) and a ChannelModule screen (in StationUI's Station/ChannelModules.swift); StationTheme is the enum/key in StationCore/Core/StationThemeKind.swift, with its UI roles in StationUI/Core/StationTheme.swift. See channel-modules.md.
  • No compile flags across packages. Targets ask AppKind.current (.player or .manager, set in Sources/ entry points) instead of #if MANAGER.
  • package vs public visibility. Targets inside Packages/Package.swift share internal package APIs via package access, keeping public restricted to what the @main app shells in Sources/ and cross-target boundaries actually use (with Sendable declared on public value types). Tests reach internals with @testable import.

History & retired shims #

Earlier stages split the codebase across six separate SwiftPM packages (RetroLineup, RetroRelay, Station, StationUI, Players, ManagerUI) and included a Swift server target (StationServer, Sources/AntennaTower), standalone Manager job loops, Linux compatibility shims (CSQLite, LinuxLogger.swift, NoCloud.swift, swift-crypto, just linux-check), and access-rewriting scripts (scripts/publicize.py, scripts/fix-access-errors.py). Once Antenna Tower moved to Go (tower/) and the Manager became a pure remote client, those separate manifests, server targets, Linux shims, and scripts were retired and the remaining Swift targets consolidated into Packages/Package.swift.

just check-tvos emits each tvOS-facing Swift module from Packages/Sources/ with -swift-version 6 and type-checks Sources/TVApp/ against the tvOS SDK.
