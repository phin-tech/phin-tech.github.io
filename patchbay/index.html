Patchbay

One place for your MCP servers and agent skills. Patchbay runs your servers, keeps their keys in the Keychain, signs in to the ones that use OAuth, and puts every one behind a single local gateway. It installs skills once and gives them to every tool that reads them. Then it points your AI tools at all of it: Claude Code, Claude Desktop, Codex, Cursor, VS Code, Gemini CLI, opencode, pi, omp and PiG.

Add a server once and every tool has it. Change a key once and every tool uses the new one, and none of them ever sees it. Add a skill once and every tool that reads skills has it too.

What it does #

  • Paste a server in. Copy what a server's README gives you (a Claude Desktop block, a claude mcp add command, an npx … line or just a URL) and paste it into Add Server (⌘N). Patchbay shows what it read before adding anything. Keys in the paste go into the Keychain; your patchbay.toml only names them.
  • Keys and sign-ins, kept for you. A server that needs a key asks for it once, in a masked field. A server that signs in with OAuth opens your browser once, and Patchbay keeps and refreshes the token. A wrong or expired key is replaced with Change Key.
  • One gateway, many tools. Every tool talks to http://127.0.0.1:7357/mcp. Connect a tool in the Clients list and Patchbay writes its entry into that tool's own config, leaving everything else in it alone, with a backup beside it.
  • Bring in what your tools already have. A tool's own servers are listed on its page. Take Over moves them into Patchbay, keys into the Keychain, and out of that tool's config, so every tool gets them.
  • Choose what each tool gets. Every server, a profile of them, or only the ones you tick. And how: one entry with every tool named after its server (linear__list_issues), an entry for each server, or compact: three tools that search for the rest and call them, so a tool with many servers keeps its context for the work.
  • Skills, the way skills.sh installs them. Paste owner/repo, a GitHub link or a whole npx skills add … line into Add Skills, tick the skills you want, and Patchbay installs them where npx skills add -g would, linked into Claude Code, Cursor, VS Code, Gemini CLI and opencode, and read by Codex and pi. It keeps the same record as the skills CLI, so the two look after one set of skills, and it checks each skill's source for changes and shows which files changed.
  • Skills you made yourself, taken over. A skill already in a tool's folder is listed as your own and left alone until you choose Take Over. Then Patchbay keeps one copy and links each tool to it, replacing only copies that are the same.
  • Patch it like a rack. The main window opens on the patch bay: a module for each tool on the left, one for each server on the right, and a cable for each server a tool gets. Drag a cable from a tool's jack to a server's to give it that server, pull one out to take it away, and flip a tool's switch to connect it. Skills hang below, patched the same way. Settings can turn it off.
  • Find anything. Every list has a filter (⌘F): type aws or linear to narrow it, or is:write is:off for the tools that can change something and are turned off.
  • Stays out of the way. Close the window and the gateway keeps running from the menu bar, out of the Dock. Turn on Open at login in Settings and it's there whenever your tools are.

Getting it #

From apps.phin.tech, or with Homebrew, which also puts patchbay on your PATH:

brew install --cask phin-tech/tap/patchbay

Patchbay runs on macOS 14 Sonoma or later and updates itself.

The command line #

The app's own binary answers a command line too:

patchbay status                         # every server and what it needs
patchbay secret me/github-token         # keep a key (pasted on stdin) in the Keychain
patchbay sign-in linear                 # sign in to an OAuth server in the browser
patchbay clients                        # which tools are connected
patchbay connect cursor --servers linear --layout compact
patchbay bridge server/linear           # a server over stdio, for a tool that only runs commands
patchbay skills add vercel-labs/agent-skills --skill web-design-guidelines
patchbay skills list                    # every skill, where it's from, and which tools have it
patchbay skills update                  # fetch what's changed at each skill's source
